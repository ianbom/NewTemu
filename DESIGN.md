# KIVORA STUDIO Design Reference

## Authority

Reference: https://equa-2.vercel.app/

Preserve composition and interaction patterns, not the original identity, photographs, or business claims. The requested agency copy, dark palette, and original studio concepts replace those elements.

## Observed Geometry

- Centered 1200px outer container, 24px horizontal padding, 80px fixed navigation.
- Full-viewport photographic heroes, centered headings and copy. Contact uses a shorter 450px desktop / 320px mobile hero.
- Geist, normal-weight hero headings, light-weight editorial headings. Hero heading breakpoints: 36px mobile, 48px small tablet, 60px tablet, 72px desktop. Contact headings: 36 / 48 / 60px.
- Homepage sections use 96px vertical padding. Editorial splits use 112px desktop / 80px mobile. Principle panels use 80px.
- Homepage image/text splits use equal columns; numbered services use a 7:5 split. Editorial closing images use 4:3; introductory About imagery uses 4:5.
- Three-column portrait expertise and service grids. Four-column featured projects. Portfolio uses a sidebar and a three-column square-image grid. Project detail uses a 7:5 split and a 4:3 gallery.
- Showcase uses mixed landscape and portrait tiles; Approach uses two-column principles; Careers uses three culture panels and a centered inquiry section.
- Square-edged uppercase CTAs, thin separators, restrained image zoom, dropdown navigation, mobile overlay navigation, and a multi-column footer.

Darkness is an explicit brand requirement. Champagne replaces the reference's orange emphasis. Photographic overlays retain readable text; no decorative glow or new SaaS-style layout is introduced. Geist preserves the source's typographic character. Motion is limited to hero arrival, interactive states, and image hover; reduced-motion users receive near-instant transitions.

The original geographical export map becomes an interactive industry/interface panel with the same prominent landscape footprint. Product options become project context, features, and technology information. Catalog actions become relevant service inquiries. No original asset is served by the application.

## Content And Interaction Boundaries

- English-only. KIVORA STUDIO; Surabaya, East Java, Indonesia; mail@agency.site; +62 851-5199-4724.
- Twelve original studio concepts. No commissioned-client claims, testimonials, fabricated team, invented history, or agency performance metrics.
- Six service categories, four portfolio categories, four process phases, four approach principles.
- Combined search/filter/pagination, gallery filtering and lightboxes, project thumbnails, category tabs, and industry controls are functional.
- Contact opens a prepared WhatsApp message or email draft. Sending remains in the user's chosen application; no backend submission is implied.
