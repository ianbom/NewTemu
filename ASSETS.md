## Original Assets

The KIVORA wordmark, favicon, social cover, and all thirty-six SVG interface compositions are created for this project. Interface compositions are generated by `scripts/generate-projects.mjs`. Concept names identify fictional studio explorations, not clients or testimonials.

The generator also creates thirty-six Indonesian-language variants in `public/images/projects/id`. These retain the original compositions with translated interface labels and adjusted text sizing. English originals remain unchanged.

## Typography And Icons

Geist: loaded through `next/font/google`. Lucide: interface icons. Radix primitives support shadcn-style accessible dialog and navigation components. Their installed packages retain upstream license files.
