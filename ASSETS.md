## Original Assets

The TemuWeb wordmark, favicon, social cover, and all thirty-six SVG interface compositions are created for this project. Interface compositions are generated by `scripts/generate-projects.mjs`. Concept names identify fictional studio explorations, not clients or testimonials.

The generator also creates thirty-six Indonesian-language variants in `public/images/projects/id`. These retain the original compositions with translated interface labels and adjusted text sizing. English originals remain unchanged.

`scripts/generate-brand.mjs` creates the TemuWeb social cover at 1200 by 630 pixels, retaining the existing dark background, typography placement, and separator composition. The favicon uses a T glyph in the existing icon dimensions and colors. Existing photography is unchanged by the TemuWeb rebrand.

## Typography And Icons

Geist: loaded through `next/font/google`. Lucide: interface icons. Radix primitives support shadcn-style accessible dialog and navigation components. Their installed packages retain upstream license files.
